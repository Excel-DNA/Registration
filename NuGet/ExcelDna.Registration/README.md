# ExcelDna.Registration

This package is deprecated. The registration helper APIs have moved into `ExcelDna.Integration`.

Existing projects that reference `ExcelDna.Registration` can continue to restore it for compatibility. New projects should reference `ExcelDna.Integration` and use the registration APIs from there.

The registration APIs help customize Excel-DNA function registration, including transformations for async functions, optional parameters, logging, caching, timing, and other registration-time behavior.
